How to label (read once)
  • Type exactly what the crop shows, in reading order, one line per row of work.
  • Math goes in as LaTeX. Words stay plain text. Example line: \int_{0}^{1} \frac{1}{\sqrt{x}}\, dx = 2
  • Two columns side by side: type the left column first, then the right.
  • Ignore arrows, circles, underlines and scribbles. Include small side notes only if you can read them.
  • Do not copy what an OCR engine produced. Type what you see, so the answer key stays independent.
  • Blank or unreadable crop: press Skip.
  • The preview under the box shows how your LaTeX renders. A red message means the LaTeX is broken, so fix it.
  • Everything saves to disk automatically. Watch the status at the top right: green means saved.
